---
name: fitted-sync
description: Review or synchronize the current Fitted branch with its configured upstream safely.
---

Use repository-configured remotes and the current branch. Never assume a team remote
or branch name. For a review, stay read-only. Fetch only when the user asks to sync.
Before changing history, summarize incoming commits and changed-file scope. Do not
push or force-push. Stop on divergence or rebase conflicts and present the concrete
choices before proceeding.
